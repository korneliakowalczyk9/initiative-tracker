# Initiative Tracker

Initiative Tracker is a discovery-stage project exploring an independent initiative-management application. Its current deliverable is a clickable prototype that uses fictional data and does not persist changes; it is not a finished web application or an approved MVP.

## Overview

Initiative Tracker aims to simplify initiative management by providing a clear overview of progress, ownership, status updates and potential risks.

The project explores product management, UX/UI design and AI-assisted software development.

## Key Features

Planned functionality includes:

- Centralised initiative dashboard
- Initiative registration and management
- Status and progress tracking
- Ownership and responsibility assignment
- Regular update monitoring
- Risk and comment tracking
- Search, filtering and status history

## Development

The project follows an iterative approach, covering product discovery, UX/UI design, technical planning, implementation and testing.

## AI assistance

AI tools were used to help draft documentation, explore design options and build the prototype. The product decisions, scope and priorities are my own: AI suggestions were treated as proposals, and only decisions I confirmed are recorded in the project documents.

## Discovery Prototype

The authorized, fictional-data status-flow prototype is available at [UI/prototype/index.html](UI/prototype/index.html). It is a non-persistent discovery artifact, not the application or an MVP approval.

## Working principles

- The project is at the discovery stage; implementation beyond the prototype waits until requirements and MVP scope are agreed.
- Confirmed requirements, assumptions and suggestions are kept distinct, and recommendations are explained rather than assumed.
- All example data is fictional.
- The prototype stays small, with no backend, authentication or persistent storage.

## Disclaimer

An independent learning and portfolio project. All example data is fictional; no confidential business information is used.
